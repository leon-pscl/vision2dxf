# Data Files

All data in this directory is **prototype-only** and not validated anthropometric data.

## Sources
- `drafting/formula_parameters.yaml`: Team-created drafting constants for Design A
- `base_blocks/bodice_medium.json`: Team-created medium base block for Design B
- `templates/*.json`: Team-created discrete templates (Small/Medium/Large) for Design C
- `usability/sus_responses.csv`: Empty template for future SUS participant responses

## Status
Every data file includes `source`, `status`, and `units` fields. All values are marked `prototype_only` and must not be presented as empirical anthropometric data.

## Units
All measurements are in centimeters (cm).
